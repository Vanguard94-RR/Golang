# Exercises - Section 3: Values, Variables and Constants (Intermediate)

## Exercise 1: Currency Converter with Multiple Rates

**Description:**
Build a currency converter that handles multiple exchange rates as constants. Convert between USD, EUR, GBP, and MXN. The program should accept an amount, source currency, and target currency.

**Expected Input and Output:**
```
Convert: 100 USD to EUR (rate 1 USD = 0.92 EUR) → 92.00 EUR
Convert: 50 GBP to MXN (rate 1 GBP = 20.5 MXN) → 1025.00 MXN
Convert: 1000 MXN to USD (rate 1 MXN = 0.059 USD) → 59.00 USD
```

**Hint:**
Define all exchange rates as constants relative to USD. Use intermediate calculations if needed.

## Exercise 2: Student Grade Calculator with Weights

**Description:**
Create a program that calculates a student's final grade based on multiple weighted components: quizzes (20%), midterm (30%), final exam (50%). Input all scores and display final grade with letter grade (A: 90-100, B: 80-89, C: 70-79, etc).

**Expected Input and Output:**
```
Quiz: 85, Midterm: 88, Final: 92 → Final Grade: 89.8 (B)
Quiz: 75, Midterm: 78, Final: 72 → Final Grade: 74.3 (C)
Quiz: 95, Midterm: 98, Final: 96 → Final Grade: 96.9 (A)
```

**Hint:**
Define weights as constants. Use conditional statements to determine letter grade.

## Exercise 3: Distance Converter (Multiple Units)

**Description:**
Create a converter that transforms between distance units: millimeters (mm), centimeters (cm), meters (m), kilometers (km), and miles. Accept a value and two units, returning the conversion.

**Expected Input and Output:**
```
100 m to km → 0.10 km
5 km to miles → 3.11 miles
1000 mm to cm → 100.00 cm
```

**Hint:**
Define conversion factors as constants. Consider using a base unit (meters) to simplify conversions.
